Project

Personal Website

A personal site for projects, writing, goals, and my CV, built from scratch with HTML, CSS, and JavaScript.

HTML CSS JavaScript GitHub Pages

This website is the central place where I collect my work, notes, goals, and CV. I built it as a lightweight static project so it stays fast, easy to maintain, and simple to deploy.

The project includes bilingual navigation, dedicated sections for posts and goals, a web CV with downloadable PDFs, reusable data files for featured content, and responsive styling across desktop and mobile screens.

I wanted a page that feels more personal than a standard profile link and more flexible than a PDF. It gives me one place to show what I am working on, write about what I am learning, and keep the public version of my CV current.
